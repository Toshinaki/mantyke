# UI 测试用例设计

适用范围：`@mantyke/spotlight-image`、`@mantyke/masonry`。

## 1. 设计原则

1. **用例从用户体验出发。** 每条用例描述用户在做什么、应当看到什么，预期结果不参考当前实现。测试不通过时，默认视为代码问题，汇总后报告。
2. **预期必须可以测量。** 「完整显示」「不变形」这类描述都附带判定方法，保证自动化测试能给出明确的通过或失败。
3. **优先级分两级。**
   - P0：基本功能。不满足时用户会认为组件坏了，按缺陷处理。
   - P1：体验质量。不满足时组件仍可用，但体验明显不如同类组件，按体验问题报告。

## 2. 测试分层

| 层 | 工具 | 负责内容 |
| --- | --- | --- |
| L1 逻辑测试 | jest + jsdom（维持现状） | props、事件、状态切换 |
| L2 交互测试 | Storybook `play` 函数 + `@storybook/addon-vitest`，在 Chromium 中运行 | 本文档第 4、5 节的用例，实现见 [spotlight-image.ui-test.story.tsx](../packages/spotlight-image/src/spotlight-image.ui-test.story.tsx)、[masonry.ui-test.story.tsx](../packages/masonry/src/masonry.ui-test.story.tsx) |
| L3 视觉回归 | Vitest browser mode 截图对比 | 本文档第 4.7、5.4 节的状态截图 |
| L4 实机确认 | 人工检查清单 | 本文档第 6 节 |

运行方式：`pnpm test:ui`。L2 和 L3 在 Mantine 8 与 Mantine 9 下各运行一遍。大版本升级时，L3 的截图差异和 L4 清单全部确认后才能发布。

## 3. 测试素材与环境

### 3.1 测试图片

所有测试图片由 [generate-test-fixtures.ts](../scripts/generate-test-fixtures.ts) 生成 JPEG 并提交到仓库，不使用网络图片。图片规格集中定义在 [fixtures.ts](../.storybook/fixtures.ts)，修改后运行 `pnpm fixtures:generate` 重新生成。每张图片包含以下元素：

| 元素 | 用途 |
| --- | --- |
| 对角线方向的双色渐变底色 | 平移或缩放后，能从颜色看出当前显示的是图片的哪个部分 |
| 每 10% 一条的网格线 | 判断缩放倍数和平移距离 |
| 四角各一个不同颜色的三角标记 | 判断图片是否被裁切、翻转 |
| 中心的正圆和十字线 | 圆变成椭圆说明图片变形；十字线用于判断是否居中 |
| 大号编号与尺寸文字（如 `#3 800×1200`） | 核对顺序、遗漏和重复 |

SpotlightImage 用图：

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `landscape-3000x2000` | 3000×2000 | 常见的大尺寸横图 |
| `portrait-2000x3000` | 2000×3000 | 大尺寸竖图 |
| `small-400x300` | 400×300 | 小于屏幕的图片 |
| `panorama-6000x1000` | 6000×1000 | 极端宽图 |
| `tall-600x4000` | 600×4000 | 极端长图（如长截图） |
| `huge-8000x6000` | 8000×6000 | 超高分辨率图片 |

Masonry 用图：12 张，渐变配色各不相同，宽高比依次为 3:2、2:3、1:1、16:9、9:16、4:3、3:4、3:1、1:3、3:2、2:3、1:1。另外准备一组文字卡片，高度在 80px 到 400px 之间，用于非图片内容的场景。

加载慢和加载失败的图片由 story 内部模拟（延迟设置 `src`、使用不存在的地址），不依赖网络限速。

## 4. SpotlightImage

以下两项体验做成可选配置，默认关闭，保持与当前版本一致的行为。相关用例在开启和关闭两种状态下各测一次。

| 配置 | 开启方式 | 默认 | 对应用例 |
| --- | --- | --- | --- |
| 点击空白处关闭 | `modalProps={{ closeOnClickOutside: true }}` | 关闭 | SI-06a、SI-06b、SI-06c |
| 限制拖动范围 | `keepImageInView`（暂定名称，尚未实现） | 关闭 | SI-54a、SI-54b |

SI-38（滚轮以鼠标位置为中心缩放）为非必须的体验改进：能实现就实现，实现成本过高时可以放弃。

## 5. Masonry

Masonry 的用户分两类：浏览图片的访问者，以及把组件接入页面的开发者。5.1 至 5.2 从访问者角度检查显示效果；5.3 从开发者角度检查数据变化后的表现。

### 5.1 显示效果（三种变体都执行）

| ID | 优先级 | 场景 | 操作 | 预期体验（判定方法） |
| --- | --- | --- | --- | --- |
| MA-01 | P0 | 内容完整 | 放入 12 张图片 | 12 张都显示，编号无遗漏、无重复 |
